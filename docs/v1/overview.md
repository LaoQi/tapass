# V1 版本概述

## 设计目标

tapass V1 是密码管理器的首个版本，实现核心的密码存储与加密保护功能。

## 功能范围

- 基于主密码的加密存储
- 二进制文件格式，支持完整性与密码验证
- XChaCha20-Poly1305 AEAD 加密
- Argon2id 密钥派生 + HKDF 子密钥拆分

## 技术选型

| 组件 | 选型 | 说明 |
|------|------|------|
| 密钥派生 | Argon2id | 抗 GPU/ASIC，内存硬化 |
| 子密钥拆分 | HKDF-SHA256 | 安全拆分派生密钥，避免密钥复用 |
| 加密算法 | XChaCha20-Poly1305 | AEAD，兼顾机密性与完整性 |
| 压缩算法 | zlib/DEFLATE | 压缩在加密前执行，减少密文体积 |
| 头部校验 | SHA-256 + HMAC-SHA256 | 双层校验：数据完整性 + 主密码验证 |

## 文件格式

- 二进制格式，头部 144 字节明文 + 变长密文体
- 小端序（Magic 除外）
- 详见 `data-structures.md` 和 `crypto-model.md`
